# cats_gallery Весёлые коты

NP-трудная задача: выбрать лучшего котика.
(Приложение для голосования за понравившегося конкурсанта. Применимо не только к котам.)

Для запуска локального хоста воспользуйтесь `cats.py`.

Приложение поддерживает возможность проголосовать одним голосом за каждого конкурсанта.
При повторном нажатии кнопки `+1`, голос будет отозван.
В наличии возможность добавить 30-символьный комментарий.
Голоса и комментарии отправляются на запись в базу данных `cats.db`. Из этой же базы происходит считывание при обновлении страницы.
Обсчёт голосов, добавление комментариев и выделение лидирующего конкурсанта
реализовано с помощью javascript на локальной странице пользователя.

Голосование можно проводить ограниченное время, после чего формировать список победителей
и выявить лидеров среди нового созданного списка конкурсантов.
